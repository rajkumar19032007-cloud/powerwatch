Cloud Computing Architecture & Defense Guide Capstone Technical Reference

Detailed documentation of cloud computing paradigms, NoSQL schema, serverless pipelines, and security rules.

End-to-End Cloud Telemetry Flow

1. IoT Edge Sensing
Current sensors, CT coils, and Modbus smart meters sampling at 1 Hz.
2. Serverless API
Cloud Functions endpoint validating JWT tokens and normalizing telemetry.
3. Cloud Firestore
Low-latency NoSQL database with auto-scaling document partitions.
4. Real-Time Engine
WebSocket snapshot subscribers updating client browsers without polling.
5. Event Alerts
Automated anomaly triggers for spikes, low PF, and nighttime overloads.

12 Cloud Computing Concepts Implemented

1. Cloud Authentication (IDaaS)

Identity-as-a-Service using Firebase Auth with secure salted password hashing, JWT ID token issuance, and session expiration management.

2. Scalable NoSQL Document Database

Google Cloud Firestore schema with hierarchical sub-collections (`buildings/{id}/devices`), indexing, and ACID transaction guarantees.

3. Real-Time Cloud Synchronization

Bi-directional WebSocket streams pushing changes to all connected operator screens with sub-second latency via `onSnapshot` listeners.

4. Serverless Edge Computing

Zero-server infrastructure where backend workloads scale automatically from 0 to thousands of concurrent sensor streams on demand.

5. IoT Edge-to-Cloud Telemetry Pipeline

Simulated physical meters generating Voltage, Current, Power, Frequency, and Power Factor metrics with diurnal campus profiles.

6. Multi-Tenant Campus Hierarchy

Hierarchical asset data modeling supporting campus-wide aggregation, building sub-meters, and individual circuit breaker diagnostics.

7. Role-Based Access Control (RBAC)

Tiered permission governance (Admin, Energy Manager, Viewer) enforcing data isolation and write privileges across sensitive configuration endpoints.

8. Declarative Cloud Security Rules

Production-grade `firestore.rules` validating authorization tokens on the database server to prevent unauthorized writes or tampering.

9. Automated Cloud Report Generation

On-demand rendering and export of printable PDF audits and CSV data sets for institutional compliance and energy audits.

10. Event-Driven Anomaly Detection

Rule-based event triggers flagging power spikes (>40%), off-hours vampire draws, and power factor degradation in real-time.

11. Statistical Predictive Forecasting

Transparent Holt-Winters seasonal exponential smoothing models predicting 24-hour and 7-day electrical demand curves with 95% confidence intervals.

12. Cost & Carbon Footprint Modeling

Dynamic Time-of-Use (ToU) tariff engine calculating base consumption costs, peak penalty incidence, and grid carbon emissions (kg CO₂e).
